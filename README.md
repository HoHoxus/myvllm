# myvllm

A personal learning project built on top of
[nano-vllm](https://github.com/GeeeekExplorer/nano-vllm).

The goal is to understand and re-implement core LLM inference components
(kernels, attention mechanisms, and inference internals) from scratch while
keeping the codebase small and readable.

## Roadmap

- ✅ Flash Attention kernel (Triton)
- ✅ Paged Attention kernel
- ⬜ Prefill-Decode Disaggregation
